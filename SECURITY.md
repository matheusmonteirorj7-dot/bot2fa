# Segurança

Não abra issues, pull requests ou mensagens contendo tokens de bot, sementes/chaves 2FA, QR codes, códigos de autenticação ou códigos de recuperação.

Este projeto foi intencionalmente desenhado para não receber esses dados. Se uma chave 2FA for exposta, remova/reconfigure o 2FA no serviço correspondente e revogue códigos de recuperação antigos. Se o token do bot for exposto, regenere-o no Discord Developer Portal e atualize a variável de ambiente no Render.
